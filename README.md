# Venue Manager - Project B

Project B continues the Project A concert venue management system and ports it to a JavaFX GUI using MVC.

## Main Files

- `VenueManagerApp.java` starts the JavaFX application.
- `VenueModel.java` stores the venue data, observable table data, and business rules.
- `VenueView.java` builds the JavaFX interface and modal forms.
- `VenueController.java` receives view actions and calls the model.
- `VenueManager/BaseClasses` contains the Project A domain classes.

## JavaFX Scope

This project uses JavaFX material from weeks 7 to 9:

- stages and scenes
- `VBox` and `HBox`
- labels, buttons, and text fields
- event handlers
- properties and binding
- modal windows
- `ObservableList`
- `TableView` and `TableColumn`

Week 10 graphics, animation, sprites, and shape classes are intentionally not used.
